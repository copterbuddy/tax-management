## 1. แอปนี้คืออะไร

**Tax Tracker** คือเว็บแอปหน้าเดียว (Single Page Application) สำหรับ **คนไทยคนเดียว** ที่ลงทุนในหุ้นต่างประเทศและคริปโตเคอเรนซี ใช้คำนวณภาษีเงินได้บุคคลธรรมดา (ภ.ง.ด.90/91) จาก

1. **กำไรจากการขายหลักทรัพย์ต่างประเทศ** (capital gain) — เมื่อโอนเงินกลับเข้าไทย
2. **เงินปันผลจากหุ้นต่างประเทศ** (dividend) — พร้อมเครดิตภาษีหัก ณ ที่จ่ายต่างประเทศ

### ลักษณะสำคัญ

| หัวข้อ | ค่า |
|---|---|
| ผู้ใช้ | 1 คน (single user) ไม่มีระบบ login |
| ที่เก็บข้อมูล | `localStorage` ของเบราว์เซอร์เท่านั้น |
| Backend | **ไม่มี** — ไม่มี server, ไม่มี API, ไม่มี network call ใด ๆ |
| การส่งข้อมูลออก | ไม่มีเลย ข้อมูลไม่เคยออกจากเครื่องผู้ใช้ |
| ภาษา | ไทย (ค่าเริ่มต้น) / อังกฤษ |
| ธีม | Dark (ค่าเริ่มต้น) / Light |

ผลที่ตามมา: แอปทำงานได้แบบ offline 100% แต่ **ข้อมูลผูกกับเบราว์เซอร์เครื่องเดียว** — เปลี่ยนเครื่อง/ล้าง browser data = ข้อมูลหาย และไม่มีระบบ export/import ใน UI ปัจจุบัน

## 2. ปัญหาที่แอปนี้แก้

การคำนวณภาษีจากหุ้นต่างประเทศของคนไทยมีความซับซ้อนที่คนทั่วไปทำผิดบ่อย 4 จุด:

```text
ปัญหา 1: ต้องรู้ว่าขายหุ้นตัวไหน "ต้นทุนเท่าไหร่"
         -> ผู้ใช้ซื้อหลายครั้งในราคาต่างกัน ต้องใช้ FIFO

ปัญหา 2: ขาดทุนหักกับกำไรไม่ได้ (ตามประมวลรัษฎากร)
         -> ต้องแยกกำไร/ขาดทุนออกจากกัน ไม่ใช่รวมสุทธิ

ปัญหา 3: กำไรจะเกิดภาษีก็ต่อเมื่อ "โอนเงินกลับเข้าไทย"
         -> ปีภาษี = ปีที่โอน ไม่ใช่ปีที่ขาย

ปัญหา 4: อัตราแลกเปลี่ยน ณ วันโอน != วันซื้อ != วันขาย
         -> ต้องใช้อัตราของวันที่โอนมาคำนวณภาษี
```

แอปนี้ encode กฎทั้ง 4 ข้อไว้ใน engine (ดู [02-trades-fifo.md](./02-trades-fifo.md) และ [03-remittance-tax.md](./03-remittance-tax.md))

## 3. หน้าจอมีอะไรบ้าง

แอปมี **หน้าเดียว** คือ Dashboard แบ่งเป็น 3 แท็บ

```text
+--------------------------------------------------------------+
|  Tax Tracker                        [TH|EN]  [Light/Dark]    |
+--------------------------------------------------------------+
|  [ ซื้อขาย ]  [ เงินปันผล ]  [ การโอนเงิน ]                   |
+--------------------------------------------------------------+
|                                                              |
|  +- Trades Tab ------------------------------------------+   |
|  |  ปีภาษี: [2025 v]        อัปเดตล่าสุด: 2025-06-01      |   |
|  |                                                        |   |
|  |  [ภาษีประมาณ]  [โอนแล้ว]  [กำไรสุทธิ]  [ยังไม่โอน]     |   |
|  |  [Dime]  [Liberator]  [FinansiaSyrus]  <- per provider |   |
|  |  ตารางรายการซื้อขาย + ปุ่มแก้ไข/ลบ                     |   |
|  +--------------------------------------------------------+   |
|                                                              |
|  +- Dividends Tab ---------------------------------------+   |
|  |  6 การ์ด KPI + ตารางเงินปันผล + ประวัติการโอน (ขยายได้) |   |
|  +--------------------------------------------------------+   |
|                                                              |
|  +- Remittances Tab ------------------------------------+   |
|  |  รวมรายการโอนทั้งหมด + ยอดรวมท้ายตาราง                 |   |
|  +--------------------------------------------------------+   |
+--------------------------------------------------------------+
```

### แท็บที่ 1 — ซื้อขาย (Trades)

แสดงกำไรส่วนทุนและภาษีที่เกิดจากการโอนเงินกลับ

- ตัวกรองปีภาษี + จุดบอกความสดของข้อมูล ("อัปเดตล่าสุด" = วันที่ของ trade ล่าสุด)
- KPI 4 ใบ: ภาษีประมาณการ (บาท), ยอดโอนแล้ว (USD), กำไรสุทธิ (USD), ยอดที่ยังไม่โอน (USD)
- KPI แถวที่สอง: แยกตามโบรกเกอร์ (Dime / Liberator / FinansiaSyrus) พร้อม % สัดส่วนภาษี
- ตารางรายการ: เรียงได้ (วันที่/สัญลักษณ์/โบรกเกอร์) กรองตามโบรกเกอร์ได้
- บันทึก **การโอนเงิน** (remittance) แนบกับรายการขายแต่ละรายการ

### แท็บที่ 2 — เงินปันผล (Dividends)

- KPI 6 ใบ: เงินปันผลรวม (USD), ภาษีหัก ณ ที่จ่าย (USD), ยอดโอนแล้ว (USD), เงินได้ที่ต้องรายงาน (บาท), เครดิตภาษี (บาท), ยอดยังไม่โอน (USD)
- ตารางเงินปันผล: กดขยายเพื่อดูประวัติการโอนของแต่ละรายการได้
- ตัวกรองปี (อิงปีที่โอน)
- มุมมองมือถือเป็น card แยก (ไม่ใช่ตาราง)

### แท็บที่ 3 — การโอนเงิน (Remittances)

- รวมรายการโอนทั้งหมดจากทุกบัญชีมาเป็นตารางเดียว (flatten)
- แสดง `amountTHB` และ `taxableTHB` ที่คำนวณไว้แล้ว
- มีตัวกรองปีของตัวเอง + แถวรวม (tfoot)
- ลบรายการโอนได้ (ซึ่งจะ trigger การคำนวณกำไรใหม่ทั้งชุด)

## 4. สิ่งที่แอป **ไม่** ทำ

ระบุไว้เพื่อกันความเข้าใจผิด:

- ❌ ไม่ดึงอัตราแลกเปลี่ยนอัตโนมัติ — ผู้ใช้กรอก FX เองทุกครั้ง
- ❌ ไม่ยื่นแบบภาษีออนไลน์ — แค่คำนวณให้ดู
- ❌ ไม่รองรับหุ้นไทย / กองทุนรวมไทย
- ❌ ไม่รองรับการนำเข้าข้อมูลจาก broker (มี action `importTrades` แต่ไม่มี UI)
- ❌ ไม่มีระบบ sync / backup / multi-device
- ❌ ไม่ได้คำนวณภาษีขั้นสุดท้าย — แสดงเพียง **เงินได้พึงประเมิน** ส่วนที่ต้องเอาไปกรอกในแบบ
  (มี calculator ภาษีขั้นบันไดอยู่ใน `taxSlice` แต่ **ยังไม่ถูกต่อเข้า UI** — ดู [05-data-and-dev.md](./05-data-and-dev.md))

## 5. คำศัพท์ที่ใช้ในเอกสารชุดนี้

| คำ | ความหมาย |
|---|---|
| **Trade** | รายการซื้อ (BUY) หรือขาย (SELL) หลักทรัพย์ 1 ครั้ง |
| **Lot** | ก้อนหุ้นที่ได้มาจากการซื้อ 1 ครั้ง ใช้เป็นหน่วยของ FIFO |
| **FIFO** | First-In-First-Out — ขายต้องตัดก้อนที่ซื้อมาก่อน |
| **Remittance** | การโอนเงินจากบัญชีต่างประเทศกลับเข้าไทย — **จุดที่ภาษีเกิดขึ้น** |
| **Proceeds / Revenue** | เงินที่ได้จากการขาย (หลังหักค่าธรรมเนียม) |
| **Cost basis** | ต้นทุนของหุ้นที่ถูกขายไป (ตาม FIFO) |
| **Realized gain** | กำไรที่เกิดขึ้นจริงแล้วจากการขาย = proceeds − cost basis |
| **`gainPercent`** | สัดส่วนกำไรต่อ proceeds ใช้แยกส่วนกำไรออกจากเงินที่โอน |
| **WHT** | Withholding Tax — ภาษีหัก ณ ที่จ่ายที่ประเทศต้นทางหักไปแล้ว |
| **Taxable gain** | กำไรส่วนที่ต้องเสียภาษีไทย (เฉพาะส่วนที่โอนแล้ว) |
| **Snapshot (THB)** | ค่าที่แปลงเป็นบาท ณ วันเกิดรายการ ใช้แสดงผลอ้างอิง |
| **Provider** | โบรกเกอร์: Dime / Liberator / FinansiaSyrus |
| **DTA** | Double Tax Agreement — อนุสัญญาภาษีซ้อน |
